# vuln-auto-fix-system
# 脆弱性自動修正システム

機械学習（LSTM）と生成AI（Gemini）を組み合わせた、ソースコードのセキュリティ脆弱性自動検知・修正パイプラインです。

## 概要
PHPソースコードの脆弱性（CWE-79, CWE-89等）を自動検知し、安全なコードへ修正します。LLMのAPIコストと処理時間を削減するため、LSTMを一次フィルターとするハイブリッド構成を採用しています。

## 処理フロー
1. **一次スクリーニング:** LSTMモデルが対象ファイル群から危険なコードを高速抽出。
2. **詳細分析と修正:** Gemini APIが脆弱性の根本原因を解説し、修正コードを生成。
3. **品質担保（門番）:** Pythonから `php -l` と `Progpilot` を自動実行し、修正コードの構文と安全性を客観的にテスト。
4. **自己修復（能動学習）:** テストを通過したコードのみを正解データとしてLSTMに再学習させ、過剰検知を防ぐ。

## 工夫した点（アピールポイント）
- **AIのハルシネーション対策:** LLMの修正案を鵜呑みにせず、外部のルールベース静的解析ツールと連携させることでデータ汚染を防止しています。
- **過剰検知へのアプローチ:** LSTMが未知の高度な安全コード（PDO等）を誤検知する課題に対し、自律的な再学習ループを構築しました。

## 使用技術
- Python 3.10
- TensorFlow / Keras (LSTM)
- Gemini API (LLM)
- Progpilot (静的解析ツール)
- PHP
